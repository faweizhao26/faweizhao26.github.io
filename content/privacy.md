本网站（faweizhao26.github.io，以下简称"本站"）由 Fawei 运营。我们重视您的隐私。本政策说明本站如何收集、使用和保护信息。

## 我们收集的信息

**本站本身不收集任何个人信息**，不设置注册、登录，也不要求您提供任何个人资料。您浏览本站时，以下第三方服务可能会处理您的数据：

### 1. 托管与访问日志（GitHub Pages）

本站托管于 GitHub Pages。GitHub 作为托管服务商，可能会记录访问请求的标准服务器日志（如 IP 地址、访问时间、请求页面）。详情请参阅 [GitHub 隐私政策](https://docs.github.com/zh/site-policy/privacy-policies/github-privacy-statement)。

### 2. 访问统计（Umami Cloud）

本站使用 [Umami Cloud](https://umami.is) 进行匿名访问统计。Umami 不使用 Cookie、不采集个人身份信息，仅统计页面浏览量、访问来源、设备类型等聚合数据，用于了解内容的受欢迎程度。详情请参阅 [Umami 隐私政策](https://umami.is/privacy)。

### 3. 阅读量统计（不蒜子 / vercount）

本站使用不蒜子（[vercount](https://cn.vercount.one)）统计文章阅读量。该服务基于访问请求进行计数，可能记录访问次数与 IP 地址等信息。

### 4. 评论系统（giscus）

本站的评论功能基于 [giscus](https://giscus.app)，由 GitHub Discussions 提供支持。发表评论需要登录 GitHub 账号，您的评论内容、GitHub 用户名与头像将公开展示。详情请参阅 [GitHub 隐私政策](https://docs.github.com/zh/site-policy/privacy-policies/github-privacy-statement) 与 [giscus 官方说明](https://giscus.app/)。

### 5. 广告（Google AdSense）

本站展示 Google AdSense 广告。Google 及其合作伙伴可能会使用 Cookie（如 DoubleClick Cookie）在您访问本站及其他网站时投放广告，包括个性化广告。您可以通过 [Google 广告设置](https://adssettings.google.com) 管理或关闭个性化广告。详情请参阅 [Google 隐私政策](https://policies.google.com/privacy?hl=zh-CN)。

### 6. 图片等静态资源

本站部分图片（如头像、二维码）托管于 GitHub 的 raw 内容分发网络（raw.githubusercontent.com），加载这些图片时您的 IP 地址可能会被 GitHub 记录。

## Cookie 的使用

本站自身不使用 Cookie。上述第三方服务（尤其是 Google AdSense）可能会使用 Cookie，具体请参阅各服务的隐私政策。您可以通过浏览器设置随时禁用或删除 Cookie。

## 数据共享

我们不会出售、出租或交易您的个人信息。我们仅在法律要求或为保障服务安全时，配合相关执法机关提供必要信息。

## 您的权利

您有权：

- 通过浏览器设置禁用或清除 Cookie；
- 通过 [Google 广告设置](https://adssettings.google.com) 退出个性化广告；
- 通过浏览器开启"请勿跟踪"（Do Not Track）；
- 就个人信息相关问题联系我们。

## 儿童隐私

本站不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

## 政策更新

我们可能不时更新本隐私政策。更新后将在本页面公布，并在页面顶部标注新的更新日期。重大变更时，我们会在首页进行提示。
